# Отчет по лабораторной работе №1

## Тема: Скрипты Python для автоматизации управление архитектурой

Изучите скрипт. Его задача: Анализ логов веб-сервера Nginx, выявление IP-адресов, с которых идет подозрительно много 404-х ошибок (попытка сканирования уязвимостей), и отправка оповещения в Telegram.

## Ответы на вопросы

1. Какие библиотеки используются в скрипте? Опишите функции  которые они предоставляют.

-re (Regular Expressions): Библиотека для работы с регулярными выражениями.
Функция findall() модуля re возвращает все неперекрывающиеся совпадения шаблона pattern в строке string в виде списка строк или список кортежей. Строка сканируется слева направо, и совпадения возвращаются в найденном порядке.

-collections.Counter — счётчик (стандартная библиотека Python)
Назначение: удобный подсчёт количества вхождений элементов в итерируемом объекте.

Counter(iterable) — создаёт словарь-наследник dict, где ключи — уникальные элементы, значения — сколько раз каждый встретился.
.items() — возвращает пары (элемент, количество), по которым скрипт итерируется.

-requests: Библиотека для отправки HTTP-запросов.
Модуль позволяет чрезвычайно легко отправлять HTTP/1.1 запросы. В скрипте используется функция requests.post для отправки сообщения в Telegram API.

2. Какое окружение нужно обеспечить, чтобы скрипт заработал? 

Чтобы скрипт заработал, нужно обеспечить следующее:

Программное окружение
Python 3.7+ (используются f-строки).

Установленная сторонняя библиотека requests.

Остальные модули (re, collections) входят в стандартную библиотеку Python.

Доступ в интернет с машины, где запускается скрипт — для обращения к api.telegram.org (порты 80/443). Если есть корпоративный прокси — его надо настроить в переменных HTTP_PROXY/HTTPS_PROXY или в requests.

Доступ к файлу логов (в текущей версии лог встроен в код, но для реальной работы нужны права чтения файла журнала Nginx, например /var/log/nginx/access.log — обычно требуется sudo или членство в группе adm).

Telegram-часть
Бот в Telegram, созданный через @BotFather — от него получают TELEGRAM_TOKEN.

CHAT_ID — идентификатор чата/пользователя, куда бот будет слать сообщения. Получить его можно, например, через метод getUpdates после отправки боту любого сообщения, или через сторонние боты вроде @userinfobot.

Пользователь должен хотя бы раз написать боту /start — иначе Telegram не даст боту отправить ему сообщение (политика приватности ботов).

Логи Nginx
Для проверки скрипта «как есть» ничего не нужно — лог в нём вшит в код строкой. Для работы с настоящим логом Beget понадобится файл access.log (или его копия), доступный на диске.

Формат лога должен содержать IP и код ответа 404 в том порядке, в котором его ожидает регулярка (стандартный формат Nginx combined — подходит).
